# Bird-Deterrent
Files related to the iterative design of the Audio Bird Deterrent, for online access and reference. 

This holds the Arduino project files, with folders holding the last edit to a current version. These versions mark milestone updates in the software, and are differentiated by that functionality. Small patches are updated locally, and won't be published to this repository. 

GERBER files for the circuit board are included for viewing here as well.
